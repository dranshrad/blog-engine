# Content Templates (condensed)

Word counts are planning estimates only — never a score gate.

## how-to-guide (~2,000–2,500)

**Title:** How to [Achieve X]: A [Year] Step-by-Step Guide  
**Use:** Sequential processes with ≥3 meaningful steps.

1. Intro — problem, cost of inaction, promise, credibility
2. Prerequisites checklist (tools, time, difficulty)
3. Steps as H2/H3 — one action each; screenshot/diagram per critical step
4. Verification / success criteria
5. Common mistakes + troubleshooting
6. Optional FAQ
7. Conclusion + next-step CTA

## listicle (~1,800–2,500)

**Title:** [N] Best [Things] for [Audience] in [Year]  
**Use:** Curated sets with clear selection criteria.

1. Intro + criteria for inclusion
2. Key Takeaways or quick comparison table
3. Each item as H2: who it’s for, pros/cons, evidence, verdict
4. How to choose / decision framework
5. Conclusion

## comparison (~1,800–2,400)

**Title:** [X] vs [Y]: Which Is Better for [Use Case]?  
**Use:** Head-to-head decisions.

1. Answer-first verdict for common use cases
2. Comparison table (features, pricing, limits)
3. Deep sections per dimension
4. Who should pick X / Y
5. Migration or switching notes
6. Conclusion

## pillar-page (~3,000–5,000)

**Title:** The Complete Guide to [Topic] ([Year])  
**Use:** Hub content for a cluster.

1. Scope + who this is for
2. Foundations
3. Core subtopics (link out to cluster spokes)
4. Frameworks / playbooks
5. Tools and resources
6. FAQ
7. Conclusion + cluster map links

## product-review (~1,800–2,500)

**Title:** [Product] Review ([Year]): Is It Worth It?  
**Use:** Evaluation with transparent methodology.

1. Verdict box (score, best for, not for)
2. Methodology (what was tested, for how long)
3. Features / UX / pricing / support
4. Pros/cons
5. Alternatives
6. Final recommendation

## thought-leadership (~1,500–2,200)

**Title:** [Point of View]: [Specific Claim]  
**Use:** Opinion backed by evidence, not vibes alone.

1. Thesis
2. Evidence + counterarguments
3. Implications
4. Practical recommendations
5. Open questions

## tutorial (~2,000–3,000)

**Title:** [Build/Do X] with [Tool]: Full Walkthrough  
**Use:** Code or tool demos with copy-pasteable steps.

1. What you’ll build + finished result
2. Environment setup
3. Implementation steps with code blocks
4. Edge cases / debugging
5. Next extensions

## news-analysis (~1,200–1,800)

**Title:** [Event]: What Changed and What To Do  
**Use:** Algorithm updates, product launches, policy changes.

1. What happened (sourced)
2. Who is affected
3. What changed vs before
4. Action checklist
5. Watch-fors / unknowns

## data-research (~2,000–3,000)

**Title:** [Finding]: [Study/Survey] Results  
**Use:** Original or deeply re-analyzed data.

1. Headline finding
2. Methodology + limitations
3. Key charts
4. Segment breakdowns
5. Implications
6. Raw-data / reproducibility notes

## faq-knowledge (~1,200–2,000)

**Title:** [Topic] FAQ: [Primary Question]  
**Use:** Definitional / knowledge-base intent.

1. Direct definition answer
2. Related questions as H2s (answer-first)
3. Examples
4. Related resources

## roundup (~1,800–2,500)

**Title:** [N] Experts on [Topic]: [Angle]  
**Use:** Multi-source expert collection.

1. Why this roundup
2. Expert contributions (quote + context + takeaway)
3. Synthesis themes
4. Practical checklist

## case-study (~1,500–2,200)

**Title:** How [Subject] Achieved [Result] with [Approach]  
**Use:** Before/after with metrics.

1. Results snapshot
2. Starting situation
3. Approach / timeline
4. Results with evidence
5. Lessons + transferability
6. CTA

## Marker syntax (optional in outlines)

Use placeholders while planning; resolve before delivery:

- `[STAT: …]` — sourced statistic
- `[IMAGE]` / `[CHART: type + data]` / `[VIDEO]`
- `[INTERNAL-LINK: anchor → target]`
- `[CTA: …]`
- `[INFO-GAIN: …]` — only with real evidence
