# Atom → Format Matrix

| Atom type | Best formats | Avoid |
|-----------|--------------|-------|
| proof | LinkedIn post, carousel comparison, short video beat | Vague hype posts |
| story | Thread, LinkedIn lore post, Reel storytime | Feature lists |
| steps | Carousel, thread (1 step/post), Shorts series | Single cryptic tweet |
| contrarian | Hook + short post, debate starter | Unsupported shock |
| definition | Single crisp post, carousel “myth vs fact” | Long essays on X |

## Cast pack template

```markdown
## Cast pack — [source title]
### Atom A1 — [one-liner]
- Type: proof|story|steps|contrarian|definition
- Evidence: [ledger id or qualitative]
- Derivatives:
  1. LinkedIn post — [when]
  2. X thread — [when]
  3. Carousel — [when] — visual: [need]
```
