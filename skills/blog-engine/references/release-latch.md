# Release Latch

Packaging gate before CMS/handoff. Complements Ship Scan + CLEAR.

## Required

- [ ] Canonical markdown (or platform source)
- [ ] Claim ledger + CLEAR scorecard attached or linked
- [ ] Residual risks empty or user-accepted
- [ ] Hero / OG image plan resolved
- [ ] Internal links intentional
- [ ] Mirror Markup validated against visible fields (if used)

## Optional artifacts

- HTML/PDF export via `studio-desk` Export Pack
- Social cast pack via `social-cast` atomize
- Preview notes for mobile width

## Blocking line

```
LATCH: open | closed
```

`closed` only when required boxes pass.
