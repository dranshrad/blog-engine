# Locale Lattice

Plan international versions without inventing cultural facts.

## Depth levels

| Level | Meaning |
|-------|---------|
| Translate | Language swap; preserve structure |
| Localize | Examples, units, idioms, CTAs |
| Market adapt | Regulatory, payment, trust patterns |

## Artifacts

1. Locale list + depth per locale
2. Glossary of locked terms
3. Hreflang pairing table
4. Parity checklist (sections, claims, CTAs, schema language)
5. Freshness rule (who updates which locale)

## Parity (blocking before “done”)

- Same primary job per locale URL
- No orphan locales without return hreflang
- Claims re-verified for market truth (pricing, law)

Hand prose polish to `editorial-pass` with Locale Lock.
