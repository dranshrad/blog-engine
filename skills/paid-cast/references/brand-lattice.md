# Brand Lattice

Constraint grid for paid creative and landing claims.

## Cells

| Cell | Content |
|------|---------|
| Allowed claims | Proof-backed statements only |
| Banned claims | Legal / brand / competitor landmines |
| Tone | Voice notes; no parody of competitors |
| Offers | Discount / trial rules and expiry honesty |
| Sensitive | Health, finance, kids, politics — escalate |
| Exclusions | Placements, keywords, audiences off-limits |

## Pass/fail

Creative or landing copy **fails** if it uses a banned claim, invents social proof, or contradicts `BRAND.md`.  
Failed items get PROBE-style fixes via `editorial-pass` / `blog-engine`, not “just launch it.”

## Evidence

Every allowed claim should point to a source the advertiser owns or a public fact the user verifies.
