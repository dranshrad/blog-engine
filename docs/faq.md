# Clearcast FAQ

### What is Clearcast?
An MIT suite of Agent Skills for Claude Code, Cursor, and Cowork: blog SEO/AEO, editorial passes, social content, and multi-surface discovery — with a hard ban on fabricated statistics.

### Will the model invent numbers?
It must not when following Clearcast. Grounding Law + claim ledgers block unsupported material claims. Always review the ledger before publish.

### How do I install for Claude Code?
`bash scripts/install.sh --claude` or copy `skills/*` to `~/.claude/skills/`. See [INSTALL.md](https://github.com/dranshrad/clearcast/blob/master/INSTALL.md).

### How do I install for Cowork?
Upload each `skills/<name>/` as a skill zip via Cowork → Customize → Skills.

### Does Clearcast guarantee rankings or AI citations?
No. It improves editorial and extractability readiness; search/answer engines decide outcomes.
