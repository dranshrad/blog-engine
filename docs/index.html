Clearcast

Agent skills for Claude Code, Cursor, and Cowork: publish-ready blogs, SEO & AEO readiness, editorial refinement, social casting, and multi-surface discovery — without inventing statistics.

Install

git clone https://github.com/dranshrad/clearcast.git
cd clearcast && bash scripts/install.sh

Or copy skills/* into ~/.claude/skills/ and/or ~/.cursor/skills/. Cowork: upload each skill zip.
