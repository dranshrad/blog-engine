Groundledger

Claude Code & Cursor agent skills for grounded blog SEO, AEO, and paid media — plus editorial, social casting, and multi-surface discovery, without inventing statistics.

Formerly Clearcast; renamed to Groundledger. Not affiliated with Clearcast UK or other ClearCast apps.

Install

git clone https://github.com/dranshrad/groundledger.git
cd groundledger && bash scripts/install.sh

Or copy skills/* into ~/.claude/skills/ and/or ~/.cursor/skills/. Cowork: upload each skill zip.
