# Clearcast

**Cursor agent skills for publish-ready blogs, editorial refinement, social casting, and multi-surface discovery.**

Clearcast helps teams write content that ranks in search, earns AI citations (AEO/GEO readiness), and ships native social packs — without inventing statistics or copying third-party plugin trees.

## Install Cursor skills

```bash
git clone https://github.com/dranshrad/clearcast.git
cp -R clearcast/skills/* ~/.cursor/skills/
```

Repo: [github.com/dranshrad/clearcast](https://github.com/dranshrad/clearcast)

## Frameworks

| Framework | Skill | Job |
|-----------|-------|-----|
| CLEAR | blog-engine | Claim-led long-form + SEO/AEO checks |
| SPARK | editorial-pass | Multi-pass polish + voice canon |
| SNAP + PULSE | social-cast | Hooks, posts, calendars, analytics |
| ORBIT | orbit-discovery | Where/why to publish |
| Studio Desk | studio-desk | Workspace, versions, export, ship |
| Cue Deck | cue-deck | Reusable prompt cards |
