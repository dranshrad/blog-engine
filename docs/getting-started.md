# Getting started

## 1. Install

```bash
git clone https://github.com/dranshrad/clearcast.git
mkdir -p ~/.cursor/skills
cp -R clearcast/skills/* ~/.cursor/skills/
```

## 2. Optional context files

In your project root: `VOICE.md`, `BRAND.md`, `CAST.md`, `ORBIT.md`, `STUDIO.md`.

## 3. First pipelines

**Article** — Ask Cursor: “Use Clearcast blog-engine to draft … with claim ledger.”  
**Social week** — “… atomize this article with social-cast.”  
**Strategy** — “… ORBIT triage for our SaaS.”  
**Workspace** — “… studio-desk boot Blog Desk named acme-blog.”
